# Ajustador de Receita Culinária

Projeto de React (Vite) — Tema 15, Programação para Internet.

Uma receita com 4 ingredientes fixos, feita originalmente para 4 porções.
O usuário informa quantas porções deseja preparar e a aplicação recalcula
todas as quantidades proporcionalmente.

## Rodando localmente

```bash
npm install
npm run dev
```

Depois abra o endereço que aparecer no terminal (normalmente http://localhost:5173).

## Usando no StackBlitz

- Crie um projeto "Vite + React" no StackBlitz e substitua os arquivos pelos
  desta pasta, mantendo a mesma estrutura (`src/components/...`).
- Ou importe este projeto direto de um `.zip` / repositório GitHub.
